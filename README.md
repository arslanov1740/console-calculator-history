# Консольный калькулятор с историей операций

Итоговый проект (Кейс 1): консольное приложение на Python для выполнения базовых
математических операций с сохранением истории вычислений в файл.

## Возможности

- Сложение, вычитание, умножение и деление двух чисел (целых и дробных, в том числе
  с запятой вместо точки — например, `3,5`).
- Сохранение истории всех успешных операций в файл `history.csv`.
- Просмотр истории операций прямо из меню программы.
- Обработка ошибок: деление на ноль, некорректный ввод чисел, некорректный пункт меню.
- Простое консольное меню для выбора действий.

## Требования к окружению

- Python 3.8 или новее.
- Внешние библиотеки не требуются — используется только стандартная библиотека
  (`csv`, `os`, `datetime`).

## Установка и запуск

```bash
git clone <ссылка-на-репозиторий>
cd <папка-проекта>
python3 calculator.py
```

Файл истории `history.csv` создаётся автоматически в той же папке при первом
запуске программы или при первом успешном вычислении.

## Использование ИИ-инструментов

В разработке использован ИИ-инструмент для генерации кода функций `get_number()`
(валидация пользовательского ввода) и `divide()` (обработка деления на ноль).
Полные промпты и сгенерированный по ним код приведены в файле [`ai_prompts.md`](./ai_prompts.md).

## Обработка ошибок

| Ситуация                          | Поведение программы                                             |
|------------------------------------|-------------------------------------------------------------------|
| Деление на ноль                    | Выводится сообщение об ошибке, программа продолжает работу       |
| Нечисловой ввод (например, "abc")  | Запрос повторяется до тех пор, пока не будет введено число        |
| Некорректный пункт меню            | Выводится сообщение об ошибке, меню показывается снова            |
