# Промпты для ИИ-генерации кода

В рамках задания использован ИИ-инструмент (в данном случае — Perplexity Computer / LLM-ассистент,
выполняющий роль, аналогичную Cursor AI и GitHub Copilot: генерация кода по текстовому промпту)
для генерации минимум двух функций проекта.

## Промпт 1 — валидация ввода пользователя

**Промпт:**
> Напиши функцию на Python `get_number(prompt: str) -> float`, которая запрашивает у пользователя
> ввод числа через `input()` с заданным текстом приглашения, поддерживает как целые, так и
> дробные числа (в том числе с запятой вместо точки — распространённая ошибка ввода в русской
> локали), и повторяет запрос, пока пользователь не введёт корректное число. Добавь docstring
> и подсказку при ошибке ввода.

**Сгенерированный код:**
```python
def get_number(prompt: str) -> float:
    """
    Запрашивает у пользователя ввод числа и валидирует его.

    Поддерживает целые и дробные числа, а также дробные числа,
    записанные через запятую (например, "3,14"). Повторяет запрос
    ввода до тех пор, пока пользователь не введёт корректное число.

    :param prompt: Текст приглашения для ввода.
    :return: Введённое пользователем число в виде float.
    """
    while True:
        raw_value = input(prompt).strip()
        normalized_value = raw_value.replace(",", ".")
        try:
            return float(normalized_value)
        except ValueError:
            print(f'Ошибка: "{raw_value}" не является числом. Попробуйте снова (например: 3.14 или 7).')
```

**Как использован в проекте:** функция `get_number` используется во всех пунктах меню калькулятора
для ввода первого и второго операнда — заменяет собой "голый" `input()` и убирает дублирование
кода валидации по всем операциям (файл `calculator.py`).

## Промпт 2 — деление с обработкой ошибок

**Промпт:**
> Напиши функцию на Python `divide(a: float, b: float) -> float`, которая делит `a` на `b` и
> корректно обрабатывает деление на ноль, выбрасывая осмысленное исключение `ZeroDivisionError`
> с понятным текстом ошибки на русском языке, а не стандартное сообщение Python.

**Сгенерированный код:**
```python
def divide(a: float, b: float) -> float:
    """
    Выполняет деление a на b.

    :param a: Делимое.
    :param b: Делитель.
    :raises ZeroDivisionError: если b равно нулю.
    :return: Результат деления a на b.
    """
    if b == 0:
        raise ZeroDivisionError("Деление на ноль невозможно. Введите ненулевой делитель.")
    return a / b
```

**Как использован в проекте:** функция `divide` вызывается из главного меню внутри блока
`try/except ZeroDivisionError`, который перехватывает исключение и выводит пользователю
понятное сообщение об ошибке вместо аварийного завершения программы (файл `calculator.py`).

## Комментарий к применению ИИ-инструментов

Использование ИИ-инструмента (в реальной разработке — Cursor AI или GitHub Copilot) в данном
проекте свелось к:

1. Генерации шаблонного, но некритичного к бизнес-логике кода (валидация ввода) — типовая
   задача, где ИИ экономит время на "boilerplate"-коде.
2. Генерации функции с обработкой исключения по явному текстовому ТЗ — демонстрация того, как
   ИИ помогает быстро закрыть edge case (деление на ноль), который часто забывают на старте.
3. Визуальное оформление проекта и поддержка с реализацией репозитория.

Основная логика меню, работы с историей (CSV) и связывание функций между собой выполнены
вручную — как ключевая часть проекта, которую важно понимать и контролировать самостоятельно
для итоговой аттестации.
